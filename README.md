# ART TONIR — сайт тюнинг-студии (Бийск)

Многостраничный сайт для тюнинг-студии **ART TONIR («Арт Тонир»)**: тонировка, антигравийная плёнка, винил и антихром, шумоизоляция, полировка.
Все факты (услуги, цены, контакты, рейтинг, отзывы) взяты из карточки студии в 2ГИС — см. `data/site.json`. Ничего не придумано: где данных нет, сайт пишет «уточните по телефону или в WhatsApp».

Общее на всех страницах: переход между страницами «плёнкой» с бликом ракеля, плавный скролл, кастомный курсор, магнитные кнопки, нижняя панель «Записаться / Звонок / Telegram / Смета» на телефоне, смета с отправкой в WhatsApp.

Каждое фото появляется с анимацией — 11 типов (соты с золотым контуром, LED-полосы, откидывание панелью, включение света с мерцанием, шторки с золотой кромкой ракеля и др.), соседние фото всегда разные. Типы раздаются в `tools/build.mjs` (объект `REVEAL`), сами анимации — в `assets/js/app.js` (`revealImg`).

## Как запустить

Это статический сайт — сборщик не нужен для просмотра.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для публикации подойдёт любой хостинг статики (GitHub Pages, Netlify, Timeweb, Beget и т. д.) — просто загрузите содержимое репозитория.

## Как менять контент

1. Правьте `data/site.json` (цены, услуги, отзывы, контакты) или тексты в `tools/build.mjs`.
2. Пересоберите страницы: `node tools/build.mjs` (нужен Node 18+).
3. Новые фото: `python3 tools/images.py <папка ArtTonir_site_kit>` — обрежет значок 2GIS и плашки «название + цена» с фото прайса, сожмёт в WebP и обновит `assets/img/manifest.json`.
   Маски для интерактивов (стёкла и кузов GLC, фото шумоизоляции): `python3 tools/masks.py <папка ArtTonir_site_kit>`.
4. Фирменные картинки (постер 3D-сцены, фон «бокса» для визуализаторов, превью ссылок `og.jpg`) рендерятся из самого сайта:
   `python3 -m http.server 8765 &` и `node tools/render-assets.mjs` — после любых правок 3D-сцены или шаблона `tools/og.html`.
5. Когда появится домен — впишите его в `SITE_URL` в `tools/build.mjs` и пересоберите (canonical, og:url, sitemap.xml).

## Технологии

HTML + CSS + чистый JS, без фреймворков. Библиотеки лежат локально в `assets/vendor/` (сайт не зависит от CDN):
Three.js 0.160 (3D), GSAP 3.12.5 + ScrollTrigger (анимации), Lenis 1.1.13 (плавный скролл). Шрифты — Google Fonts.

Сайт работает и без анимаций: при `prefers-reduced-motion` или если скрипты не загрузились, весь контент виден сразу. Если устройство не тянет WebGL, вместо 3D показывается фото бокса.

## Перед запуском уточнить у владельца

- График по дням недели и выходные (в 2ГИС только «09:00–19:00 по записи»).
- Цены на антикоррозийную обработку, утепление, бронирование фар, снятие старой тонировки, детейлинг.
- Ответы на вопросы FAQ: снятие старой тонировки, цена плёнки за метр, сроки установки.
- Оригиналы фото без значка 2ГИС и логотип в векторе (сейчас — обрисовка аватарки).
- Разрешение на фото клиентов (на сайте их нет), при желании — замазать госномера.
- Instagram / Telegram-канал, домен.
