# Продажа сайтов малому бизнесу: база + скрипт звонка

- `СКРИПТ_ЗВОНКА.md` — скрипт холодного звонка, возражения, шаблоны сообщений, план до 20 декабря.
- `tools/collect.py` — собирает из OpenStreetMap (через публичные серверы Overpass) компании, у которых есть телефон и нет сайта, в 18 крупных городах России. Сбор идёт квадратами, его можно прервать и продолжить.
- `tools/process.py` — отсеивает сети, госучреждения, алкоголь и табак, убирает дубли, раскладывает компании по нишам, считает приоритет и пишет для каждой компании персональный текст для начала разговора.
- `tools/build_xlsx.py` — собирает рабочую таблицу: «Старт», «База», «План», «Скрипт», «Сводка».

Сама база (`*.xlsx`, `leads.json`, `tiles/`) в git не попадает: репозиторий публичный, а в базе есть мобильные номера ИП.

```bash
python3 tools/collect.py tiles                 # можно указать города: tools/collect.py tiles Казань Самара
python3 tools/process.py tiles leads.json
python3 tools/build_xlsx.py leads.json СКРИПТ_ЗВОНКА.md база_клиентов.xlsx
```
